# Hospital Management System - Technical Documentation

## 1. System Overview

A multi-hospital management system that enables:
- Patient registration and account management
- Medical condition categorization and appointment booking
- Doctor-patient session management with post-visit documentation
- Surgery scheduling with consent forms and personnel tracking
- Administrative oversight across multiple hospitals
- Comprehensive audit trails and reporting

## 2. Technology Stack

- **Backend**: Python FastAPI
- **Database**: PostgreSQL
- **Frontend**: React with TypeScript
- **Authentication**: JWT tokens
- **ORM**: SQLAlchemy
- **Migrations**: Alembic

## 3. User Roles & Permissions

### Patient
- Create/manage account
- Select medical conditions from categories
- Book appointments with doctors
- View appointment history
- Sign surgery consent forms
- Access medical records

### Doctor
- View scheduled appointments
- Fill post-consultation forms
- Prescribe medications
- Request/schedule surgeries
- View patient medical history
- Update availability

### Surgeon
- All doctor permissions
- Manage surgery schedules
- Complete surgery reports
- Assign surgical team members

### Nurse
- View assigned patients
- Update patient vitals
- Assist in procedures
- View schedules

### Admin
- Manage hospital information
- Add/remove staff members
- View system-wide analytics
- Manage departments and specializations
- Configure medical condition categories
- Generate reports
- Manage bed allocation
- Approve/reject surgery requests
- Monitor billing and payments

### Super Admin
- All admin permissions across multiple hospitals
- Create new hospitals in the system
- Assign hospital admins
- System-wide configuration

## 5. API Endpoints

### Authentication
- POST /api/auth/register - Register new user
- POST /api/auth/login - Login user
- POST /api/auth/logout - Logout user
- POST /api/auth/refresh - Refresh JWT token
- POST /api/auth/forgot-password - Request password reset
- POST /api/auth/reset-password - Reset password

### Patients
- GET /api/patients/me - Get current patient profile
- PUT /api/patients/me - Update patient profile
- GET /api/patients/{id} - Get patient by ID (doctors/admins)
- GET /api/patients/{id}/appointments - Get patient appointments
- GET /api/patients/{id}/medical-history - Get medical history
- POST /api/patients/{id}/conditions - Add medical condition

### Doctors
- GET /api/doctors - List all doctors (with filters)
- GET /api/doctors/{id} - Get doctor details
- GET /api/doctors/me - Get current doctor profile
- PUT /api/doctors/me - Update doctor profile
- GET /api/doctors/me/appointments - Get my appointments
- GET /api/doctors/me/patients - Get my patients
- POST /api/doctors/me/availability - Set availability

### Appointments
- POST /api/appointments - Book new appointment
- GET /api/appointments/{id} - Get appointment details
- PUT /api/appointments/{id} - Update appointment
- DELETE /api/appointments/{id} - Cancel appointment
- GET /api/appointments/available-slots - Get available time slots

### Consultations
- POST /api/consultations - Create consultation form
- GET /api/consultations/{id} - Get consultation details
- PUT /api/consultations/{id} - Update consultation
- POST /api/consultations/{id}/prescriptions - Add prescription

### Surgeries
- POST /api/surgeries - Schedule surgery
- GET /api/surgeries/{id} - Get surgery details
- PUT /api/surgeries/{id} - Update surgery
- POST /api/surgeries/{id}/team - Add team member
- POST /api/surgeries/{id}/consent - Submit consent form
- POST /api/surgeries/{id}/report - Submit surgery report
- GET /api/surgeries/upcoming - Get upcoming surgeries

### Medical Conditions
- GET /api/conditions/categories - List condition categories
- GET /api/conditions - List conditions by category
- GET /api/conditions/{id} - Get condition details

### Hospitals
- GET /api/hospitals - List all hospitals
- GET /api/hospitals/{id} - Get hospital details
- POST /api/hospitals - Create hospital (super admin)
- PUT /api/hospitals/{id} - Update hospital
- GET /api/hospitals/{id}/departments - Get departments
- GET /api/hospitals/{id}/doctors - Get hospital doctors

### Admin
- GET /api/admin/users - List all users
- POST /api/admin/users - Create user
- PUT /api/admin/users/{id} - Update user
- DELETE /api/admin/users/{id} - Deactivate user
- GET /api/admin/analytics - Get system analytics
- GET /api/admin/reports - Generate reports
- POST /api/admin/departments - Create department

## 6. Security Features

- JWT-based authentication
- Password hashing with bcrypt
- Role-based access control (RBAC)
- Request rate limiting
- CORS configuration
- SQL injection prevention via ORM
- Input validation and sanitization
- HTTPS enforcement
- Audit logging for sensitive operations
